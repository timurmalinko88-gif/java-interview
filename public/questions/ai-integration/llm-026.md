# Distributed Tracing & Correlation IDs in OpenTelemetry

Как организовать сквозную трассировку (Distributed Tracing) цепочки вызовов пользователя, бэкенда и LLM Tools с использованием Correlation ID и OpenTelemetry?

---ANSWER---

### Короткий ответ
Каждый входящий запрос пользователя маркируется заголовком X-Correlation-ID. В OpenTelemetry создается корневой Span. Каждый вызов к LLM API и каждый последующий запуск локального Tool создаются как дочерние спаны (Child Spans) с фиксацией атрибутов (имя инструмента, токены, статус), позволяя видеть всё дерево выполнения в Jaeger/Zipkin.

### Подробное объяснение
В агентских системах один запрос пользователя может породить 3 вызова LLM и 4 вызова инструментов. Без распределенной трассировки понять, на каком именно этапе возникла задержка в 15 секунд, невозможно.

### Структура спанов в трассировке:
```
[User Request: POST /api/ai/chat] (TraceID: a1b2c3)
 ├── [Span: LLM Prompt 1 (generation)] -> 2.1s (tokens: 450)
 ├── [Span: Tool Execution: getServiceStatus] -> 0.15s (db latency)
 ├── [Span: LLM Prompt 2 (synthesis)] -> 1.8s (tokens: 280)
 └── [Response returned to user] Total: 4.05s
```

### Безопасность атрибутов в спанах (Data Sanitization):
- **Разрешено передавать в спаны**:
  - gen_ai.system: "openai"
  - gen_ai.request.model: "gpt-4o"
  - gen_ai.response.completion_tokens: 150
  - tool.name: "getServiceStatus"
- **Категорически запрещено писать в span attributes**:
  - Сырой текст пользовательских сообщений (PII).
  - Authorization API keys.
  - Персональные данные из ответов базы данных.

В Spring Boot 3 это реализуется стандартным Micrometer Observation API и аннотациями @Observed.

### Уточняющий вопрос на интервью (Follow-up)
Как связать логи в ELK и спаны в Jaeger между собой через trace_id в MDC (Mapped Diagnostic Context)?

### Распространённый неверный ответ (Pitfall)
Записывать полный prompt и тело ответа в атрибуты OpenTelemetry спанов, вызывая переполнение коллектора трассировок и утечку чувствительных данных.

### Key Points
- Каждый шаг агентского цикла должен быть отдельным дочерним спаном в трейсе.
- Передавайте X-Correlation-ID через все HTTP-запросы и асинхронные потоки.
- Используйте стандартные семантические конвенции OpenTelemetry GenAI.
- Маскируйте промпты и персональные данные перед отправкой в системы трассировки.

### Life Analogy
Почтовый трек-номер посылки: вы видите каждый промежуточный пункт сортировки (таможня, сортировочный центр, курьер) и время прохождения каждого этапа, точно зная, где произошла задержка.
