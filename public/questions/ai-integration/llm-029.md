# Google Antigravity Architecture & AI-First Engineering

Что такое Google Antigravity (AGY)? Какова архитектура платформы (Antigravity 2.0 Desktop, IDE, agy CLI, Python SDK) и чем агентная разработка отличается от чат-ботов?

---ANSWER---

### Короткий ответ
Google Antigravity — это AI-first платформа агентной разработки от Google DeepMind. В отличие от простых чат-ботов, агент Antigravity автономно исследует проект, исполняет команды, запускает фоновые задачи, создает артефакты и координирует субагентов с подтверждением ключевых архитектурных решений через Planning Mode.

### Подробное объяснение
В современной разработке произошел сдвиг от пассивных LLM-ассистентов (Copilot, ChatGPT веб-интерфейс) к **автономным агентным платформам (Agentic Development Platforms)**.

### Архитектурные поверхности Google Antigravity:
1. **Antigravity 2.0 (Desktop Application)**:
   - Левая панель: Canvas диалога и сессий.
   - Auxiliary Pane: мониторинг запущенных субагентов (Subagents), фоновых задач (Background Tasks), сгенерированных артефактов (Artifacts) и измененных файлов (Files Changed).
2. **Antigravity IDE**: Standalone среда с глубокой интеграцией AI-контекста, кодовыми линзами и встроенным терминальным монитором.
3. **Antigravity CLI (agy)**: Консольная утилита для headless-интеграции, запуска скриптов автоматизации и фонового выполнения сценариев.
4. **Antigravity SDK (Python/API)**: Программный API для аренды агентов (Agent Leasing), оркестрации пайплайнов и регистрации кастомных MCP-инструментов.

### Разница: Чат-бот vs Agentic AI
| Характеристика | Чат-бот (ChatGPT, Copilot) | Google Antigravity |
|---|---|---|
| Исполнение кода | Нет (только сниппеты) | Реальные команды терминала, фоновые демоны, тесты |
| Работа с файловой системой | Нет | Чтение, точечные правки (replace_file_content), поиск fd/rg |
| Многозадачность | 1 линейный поток | Параллельные субагенты (invoke_subagent), фоновые задачи |
| Управление сложностью | Забывает контекст | Режим Planning Mode (implementation_plan.md, walkthrough.md) |
| Взаимодействие с внешними API | Ограничено | Model Context Protocol (MCP), браузерная автоматизация Playwright |

### Уточняющий вопрос на интервью (Follow-up)
Как вы на собеседовании обоснуете использование агентных систем вроде Google Antigravity вместо классического написания бойлерплейта вручную?

### Распространённый неверный ответ (Pitfall)
Считать Google Antigravity просто еще одной вкладкой с чатом, не используя субагентов, терминальные команды и систему артефактов.

### Key Points
- Antigravity — полноценная агентная платформа с терминальным доступом и файловыми инструментами.
- Поддерживает десктопное приложение 2.0, автономную IDE, CLI agy и SDK.
- Планирование через артефакты (implementation_plan.md) гарантирует контроль над архитектурой.
- Агент способен самостоятельно запускать тесты и верифицировать результат работы.

### Life Analogy
Обычный чат-бот — это консультант по телефону, который диктует вам инструкцию. Google Antigravity — это опытный инженер, сидящий рядом с вами за клавиатурой: он сам запускает компиляцию, правит опечатки в коде, прогоняет тесты и отчитывается о результате.
