# Model Context Protocol (MCP) in Google Antigravity

Как протокол Model Context Protocol (MCP) работает в Google Antigravity? Как подключить кастомный Java/Spring Boot сервис в качестве MCP-сервера для агента?

---ANSWER---

### Короткий ответ
MCP — это открытый стандарт JSON-RPC для предоставления внешних инструментов и ресурсов языковым моделям. В Antigravity серверы MCP настраиваются через mcp_config.json (stdio или SSE). Любое Java/Spring Boot приложение может выступать MCP-сервером, объявляя свои эндпоинты через официальный SDK Spring AI MCP или JSON-RPC контроллер.

### Подробное объяснение
До появления MCP каждый инструмент требовал кастомных адаптеров. MCP (Model Context Protocol) стандартизировал подключение инструментов между процессами.

### Архитектура MCP в Antigravity:
```
[Antigravity Agent] 
       │ (JSON-RPC over stdio / HTTP-SSE)
       ▼
[MCP Server: e.g. Spring Boot Microservice]
 ├── Tools: [queryDatabase, restartPod, inspectKafkaTopic]
 ├── Resources: [app.properties, git_history, schema.sql]
 └── Prompts: [debug-memory-leak-template]
```

### Конфигурация в Antigravity (mcp_config.json):
```json
{
  "mcpServers": {
    "javaSupportService": {
      "command": "java",
      "args": ["-jar", "target/support-assistant-mcp.jar"],
      "env": {
        "SPRING_PROFILES_ACTIVE": "mcp"
      }
    }
  }
}
```

### Преимущества для Java-разработчика:
- Агент получает доступ к внутренней диагностике приложения (JMX, метрики HikariCP, дампы потоков).
- Инструменты изолированы: сервер MCP запускается в отдельном процессе с собственными правами доступа.
- Единый интерфейс взаимодействия: один и тот же MCP-сервер может использоваться в Antigravity, Claude Desktop и внешних оркестраторах.

### Уточняющий вопрос на интервью (Follow-up)
В чем различие между передачей инструментов агенту через stdio-процесс и через удаленный HTTP-SSE MCP сервер?

### Распространённый неверный ответ (Pitfall)
Пытаться писать кастомный транспорт взаимодействия с агентом вместо использования готового протокола MCP.

### Key Points
- MCP — стандарт JSON-RPC для инструментов, ресурсов и шаблонов промптов.
- Antigravity поддерживает серверы MCP через локальный stdio и удаленный SSE.
- Spring Boot приложение легко трансформируется в MCP-сервер через Spring AI MCP.
- MCP обеспечивает строгую межпроцессную изоляцию и безопасность инструментов.

### Life Analogy
MCP — это порт USB Type-C для искусственного интеллекта. Какой бы гаджет вы ни подключили (флешку, монитор, микрофон), он моментально работает через единый стандартизированный разъем.
