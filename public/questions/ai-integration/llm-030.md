# Google Antigravity Customizations: Skills, Rules & Hooks

Как устроена система кастомизации Google Antigravity? В чем различия между Skills (SKILL.md), Rules (AGENTS.md, GEMINI.md) и Hooks?

---ANSWER---

### Короткий ответ
Rules (AGENTS.md, GEMINI.md) — это постоянные или контекстные правила стиля и ограничений проекта, инжектируемые в промпт. Skills (SKILL.md) — это пошаговые инструкции и скрипты для решения узких задач (TDD, миграции, аудит), загружаемые по требованию (Progressive Disclosure). Hooks (hooks.json) — это триггеры жизненного цикла, запускающие внешние скрипты до или после вызова инструментов.

### Подробное объяснение
Antigravity Customization System превращает агента общего назначения в узкоспециализированного эксперта по вашему репозиторию.

### 1. Rules (Правила проекта):
- Файлы: AGENTS.md, GEMINI.md, .agents/rules/*.md.
- Назначение: кодовые стандарты, запрещенные библиотеки, требования к чистоте архитектуры (например, 'Всегда запускай mvn test перед коммитом').
- Иерархия: агент читает правила от текущей директории вверх до корня репозитория.

### 2. Skills (Специализированные навыки):
- Файлы: skills/<name>/SKILL.md.
- Особенность: **Progressive Disclosure**. В контекст загружается только краткое описание скилла. Полный текст инструкции загружается только тогда, когда агент или разработчик решает применить этот навык.
- Примеры: test-driven-development, systematic-debugging, spring-boot-scaffolding.

### 3. Hooks (События жизненного цикла):
- Файлы: hooks.json.
- События: pre-tool-execution, post-tool-execution, session-start.
- Назначение: автоформатирование (Spotless/Prettier) после изменения файлов агентом или линтинг.

### 4. Plugins:
- Пакеты, объединяющие набор связанных skills, rules и конфигураций MCP в один дистрибутив.

### Уточняющий вопрос на интервью (Follow-up)
Почему progressive disclosure в Skills критически важен для сохранения эффективности контекстного окна агента?

### Распространённый неверный ответ (Pitfall)
Писать огромные 50-страничные инструкции прямо в AGENTS.md, забивая контекстное окно агента до того, как он начал решать задачу.

### Key Points
- Rules (AGENTS.md) задают границы и стандарты разработки проекта.
- Skills (SKILL.md) обучают агента процедурным многошаговым методикам.
- Progressive disclosure экономит контекст и снижает галлюцинации.
- Hooks автоматизируют проверки качества кода при каждом действии агента.

### Life Analogy
Rules — это корпоративный регламент и правила безопасности в офисе (действуют всегда). Skills — это справочники и чек-листы на полке: инженер берет инструкцию по замене батареи только тогда, когда пришла задача заменить батарею.
